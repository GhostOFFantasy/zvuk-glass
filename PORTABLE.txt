ZVUK GLASS OBSERVATORY 3.0.0 — ТЕСТОВАЯ КОПИЯ

Запуск без установки
--------------------
Запустите Start-ZvukGlass-Portable.cmd. Он откроет тестовый EXE с отдельной
папкой Data рядом с ним. Туда попадут настройки, локальные данные и WebView2.

Основная установленная версия и её папка данных при таком запуске не меняются.
Данные основной версии не переносятся и не копируются автоматически: в тестовой
копии потребуется отдельный вход. Основную и тестовую копии можно держать
открытыми одновременно. Для удаления теста закройте его и удалите папку с EXE,
CMD и Data.

CMD добавляет флаг --portable: тест не перехватывает окно основной версии, а
автоматические и ручные загрузки обновлений отключены. Обычная установка без
этого флага сохраняет штатную проверку обновлений через GitHub.

Файл Zvuk-Glass-Observatory-3.0.0-Test.exe — готовая программа, не установщик.
Если открыть его напрямую без CMD, будут использованы обычные данные Zvuk Glass
из AppData\Roaming\Zvuk Glass. Для изолированного теста используйте CMD.
Параметр /shared явно выбирает обычные данные и режим основной версии.

Установщик Zvuk Glass 3.0.0 является отдельным файлом и предназначен для
обновления основной установленной копии. Не используйте его для изолированного
теста: он сохраняет фирменное имя и идентификатор приложения. Никакая установка
или публикация в GitHub не входит в подготовку этой тестовой копии.

Ключи и ограничения
-------------------
В программу не встроены пользовательские ключи Zvuk или YouTube. Собственный
ключ YouTube при необходимости добавляется в настройках. Токены хранятся с
системным шифрованием Windows. Правила сервиса Zvuk, ограничения подписки и
30-секундные превью там, где они применяются, остаются прежними.

Сборка из исходников
--------------------
Нужны Node.js, Rust и компоненты Tauri для Windows. Команды:
  npm ci
  cargo build --release --manifest-path src-tauri/Cargo.toml
После этого CMD найдёт EXE в src-tauri\target\release автоматически.
