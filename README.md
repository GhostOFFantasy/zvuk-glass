# Zvuk Glass

Неофициальный десктопный плеер для [Zvuk](https://zvuk.com) под Windows: интерфейс в духе Spotify и Яндекс Музыки, скруглённые панели и эффект «жидкого стекла». Фон и акцентные цвета подстраиваются под обложку текущего трека.

## Установка

Скачайте `Zvuk-Glass-Setup-<версия>.exe` со страницы [Releases](https://github.com/GhostOFFantasy/zvuk-glass/releases/latest) и запустите. Установщик ставит приложение только для текущего пользователя (права администратора не нужны) и создаёт ярлыки на рабочем столе и в «Пуске».

Установщик не подписан сертификатом, поэтому при первом запуске Windows может показать «Система Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Обновления

Установленное приложение само проверяет GitHub при запуске и каждые 4 часа, тихо скачивает новую версию и ставит её при выходе. Можно не ждать: в появившейся плашке нажмите **«Перезапустить»**, или откройте **Настройки → О программе → Проверить обновления**. Настройки, вход и свои файлы при обновлении сохраняются.

### Выпуск новой версии (для разработчика)

Нужны Node.js, [GitHub CLI](https://cli.github.com) и вход в него (`gh auth login --web`). Закоммитьте изменения и выполните:

```
npm run release              # 1.0.0 → 1.0.1
npm run release -- minor     # 1.0.0 → 1.1.0
npm run release -- 1.4.2 --notes "Что нового"
```

Скрипт поднимет номер версии, отправит код и тег на GitHub, соберёт установщик и опубликует релиз. Установщик без публикации собирается командой `npm run dist` (в папку `dist/`).

## Запуск из исходников

- Дважды щёлкните **`Zvuk Glass.vbs`**: приложение откроется без окна консоли.
- Ярлык на рабочем столе и в меню «Пуск»:
  ```
  powershell -ExecutionPolicy Bypass -File scripts\create-shortcut.ps1
  ```
- Из терминала (если Node.js есть в PATH): `npm start`.

## Вход в аккаунт

Пароль от Zvuk приложению не нужен. Оно работает с токеном вашей сессии:

1. Войдите на zvuk.com в обычном браузере.
2. Откройте `https://zvuk.com/api/tiny/profile`, выделите всё (Ctrl+A) и скопируйте (Ctrl+C).
3. В приложении нажмите **«Вставить»**. Токен найдётся сам.

Токен хранится только на этом компьютере и зашифрован средствами Windows (`safeStorage`). Чтобы его удалить, нажмите **Настройки → Выйти**.

> Окно входа на zvuk.com внутри приложения не работает: сайт закрывает его защитой от ботов. Поэтому вход сделан через токен.

## Возможности

- **Моя волна**: бесконечный персональный поток. Можно выбрать настроение, язык (в том числе «Без слов»), характер (любимое, популярное или незнакомое) и жанры.
- **Волны редакции**: МегаХит, ЕвроМикс, Джаз, 808 и другие.
- **Радио** по исполнителю, треку или альбому.
- **Поиск** с подсказками по мере ввода, разделом «Лучший результат», треками, исполнителями, альбомами и плейлистами.
- **Страницы** исполнителя, альбома и плейлиста.
- **Коллекция**: любимые треки (с поиском внутри), альбомы, исполнители, плейлисты, история прослушивания.
- **Плейлисты**: создание, переименование, удаление, добавление и удаление треков.
- **Лайки** треков, альбомов, исполнителей и плейлистов. Изменения синхронизируются с аккаунтом Zvuk.
- **Очередь**: «Играть следующим», «Добавить в очередь», перемешивание, повтор очереди или трека. Очередь сохраняется между запусками.
- **Тексты песен** с синхронизацией построчно. По клику на строку трек перематывается к ней.
- **Полноэкранный плеер** (клик по обложке трека): текущий трек по центру, предыдущие и следующие — по бокам в 3D. Карточки наклоняются за курсором, по клику включается трек. Кнопка «Текст» переключает на караоке-текст.
- **Визуализатор** под ритм музыки в мягком минималистичном стиле: волны, аура, столбцы, кольцо вокруг обложки. Фон — обложка, своя картинка или своё видео (видео пульсирует в такт и встаёт на паузу вместе с музыкой). Есть отдельная вкладка и режим прямо в полноэкранном плеере (кнопка «Визуализатор»). Клавиша F или двойной щелчок — во весь экран.
- **Официальные клипы с YouTube** на фоне визуализатора (фон «Клип»): приложение находит клип трека, показывает его без звука и держит в такт с музыкой; можно выбрать другой вариант, вставить свою ссылку и сдвинуть клип по времени. Для автопоиска нужен свой бесплатный ключ YouTube Data API (Настройки → «Клипы с YouTube»), по ссылке работает и без ключа. YouTube должен открываться на вашем компьютере.
- **Полоса времени** настраивается: стиль (линия, сияние, волна, жидкость), цвет, толщина, ползунок и пульс в такт музыке.
- **Два дизайна**: «Жидкое стекло» и «Обычный» — плотные тёмные панели без размытия, работает быстрее.
- **Эквалайзер** на 10 полос с пресетами (рок, поп, больше баса и др.), общим уровнем и компрессором. Показывает живой спектр и итоговую кривую.
- **Качество**: FLAC, MP3 320 или MP3 128 кбит/с. Переключается кликом по значку качества в плеере или в настройках.
- **Оформление**: свои обои (картинка или видео) или градиенты, цвет акцента из обложки или свой, плотность и размытие стекла, скругление углов, масштаб, шрифт, компактная боковая панель, мини-визуализатор в плеере, режим «меньше анимаций».
- **Профиль**: своё имя и аватар (хранятся только в приложении).
- **Медиаклавиши** клавиатуры и системный виджет Windows. Кнопки ⏮ ⏯ ⏭ есть и на миниатюре в панели задач.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Пробел | Играть / пауза |
| Ctrl + → / ← | Следующий / предыдущий трек |
| Shift + → / ← | Перемотка на 10 секунд |
| Ctrl + ↑ / ↓ | Громкость |
| M | Без звука |
| Ctrl + L | Нравится |
| Ctrl + K | Поиск |
| Alt + ← / → | Назад / вперёд (работают и боковые кнопки мыши) |
| Esc | Свернуть полноэкранный плеер |
| F | Визуализатор во весь экран |

## Ограничения

- API Zvuk неофициальный (тот же, что использует их веб-плеер). После обновлений сервиса что-то может перестать работать.
- Приложение не отправляет в Zvuk статистику прослушиваний. Поэтому то, что вы слушаете здесь, может не учитываться в рекомендациях Zvuk.
- Скачивания треков нет, только потоковое прослушивание по вашей подписке.

## Для разработки

```
src/main/zvuk-api.js   клиент API Zvuk (GraphQL + tiny REST), работает и в чистом Node.js
src/main/main.js       главный процесс Electron: окно, хранение токена, IPC
src/main/preload.js    безопасный мост к интерфейсу
src/renderer/          интерфейс (HTML/CSS/JS без сборки)
  audio-fx.js          Web Audio: эквалайзер, компрессор, громкость, анализатор
  visualizer.js        отрисовка визуализаций под ритм
  custom.js            кастомизация оформления
  np.js                полноэкранный плеер с 3D-каруселью
  vizscene.js          сцена визуализатора (вкладка и режим в плеере)
  clip.js              клип YouTube на фоне и синхронизация с треком
src/main/clips.js      поиск клипа через YouTube Data API и кэш найденного
scripts/test-api.mjs   проверка методов API: node scripts/test-api.mjs
scripts/screenshots.ps1  снимки экранов в гостевом режиме для проверки вёрстки
```

`node scripts/test-api.mjs` по умолчанию проверяет публичные методы на анонимном токене. Чтобы проверить и коллекцию, задайте переменную `ZVUK_TOKEN`.
